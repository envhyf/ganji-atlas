# 赶集志轻盈界面 Implementation Plan

**Goal:** 将赶集志改成轻盈、适合手机使用的附近集市查询页面。

**Architecture:** 保留静态 HTML、CSS 与 ES modules，在独立 light.css 中集中维护本轮视觉。更新面板文案与首页起点；只修复直接影响可见集市信息的规则对象与选点映射。

**Tech Stack:** 原生 HTML / CSS / JavaScript；现有 Python 静态服务器；浏览器验证。

- [x] 更新 site/index.html：首屏标题、浏览起点信息、加载 light.css，保留已有控件 ID。
- [x] 新建 site/css/light.css：暖白背景、系统字体、圆角卡片、横向日历、轻地图、响应式地图与列表。
- [x] 更新 site/js/panel.js：日历与列表表达，避免将乡镇数称为集市总数。
- [x] 更新 site/js/app.js、map.js：宾阳浏览起点，规则对象解析、完整选点对象、Canvas 配色与点大小。
- [x] 浏览器验证：首页与范围、日期切换、地图点选、五周表、全国、390px/768px/1440px，无横向溢出，导出结果截图。

追加修复：Canvas 集市点与 SVG 地图共用视窗变换；鼠标命中使用其逆变换；限制缩放时保持中心，忽略超过上限的滚轮缩放。tests/map-view.test.mjs 已验证缩放、平移、逆变换和缩放限制；浏览器拖动后截图显示所有点按拖动距离同步移动。

本地目录没有 Git 仓库；直接修改用户指定项目，保留改动前文件备份。视觉修改不添加镜像样式测试，以真实浏览器截图与交互核验为准。
